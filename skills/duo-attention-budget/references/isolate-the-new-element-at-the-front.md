# Isolate the New Element at the Front

## Concept

Recognising a brand-new element and applying it inside a compound task at the same time overloads working memory. Both demands fail, and — worse — failure at the compound task teaches nothing about the new element, because the user cannot tell which part they got wrong. Isolate the element first and the later mixed exercise tests integration, which is a diagnosis you can act on.

Position matters as much as isolation. The introduction belongs at the very front of the session, when capacity is highest and before the user has committed to a mode, not woven through the middle where it competes with everything already in play.

## What Duolingo does

Source: blog.duolingo.com/japanese-writing-systems (Duolingo blog, 2026-07-21; accessed 2026-09-22)

- When a Japanese lesson contains new kanji, learners first get **introductory exercises focused only on those kanji, placed at the very beginning of the lesson**, before the normal exercises begin.
- Kanji themselves are only introduced **after** learners have absorbed some hiragana and katakana — the isolation rule applies at the level of whole systems, not just individual items.

Source: blog.duolingo.com/learning-to-read-japanese-characters (Duolingo blog, 2023-09-06; accessed 2026-09-22)

- For a genuinely open-ended catalogue, Duolingo refuses the bulk-set approach entirely. Kanji are taught **as parts of whole words**, never as a character list. A kanji becomes available for focused practice in the kanji tab **only once the learner has met it inside a word**, where they can then see every learned word that uses it.
- Ordering: **hiragana first, katakana early in Section 1, kanji later in Section 1** — deliberately spread out and aligned to external standards rather than front-loaded.
- The cost: unlocking on encounter means the user cannot see or plan against the full set, and progress through an unbounded catalogue is hard to represent honestly. Duolingo accepts an unshowable denominator over a wall that reads as impossible.

## The transferable pattern

- **Give a new element its own moment before it appears in a mixed task.** One screen where it is the only unfamiliar thing. It does not need to be long — it needs to be uncontaminated.
- **Put that moment at the front.** Highest capacity, before a mode is set. An introduction buried mid-session competes with everything already loaded.
- **Layer whole systems in order, not in parallel.** If a new element depends on a system the user has not absorbed, teaching it now guarantees both fail.
- **Never present an unbounded catalogue as a set to memorise.** A large open-ended body of material shown up front has no stopping point and no anchor to meaning — it reads as an impossible wall and users quit at the sight of it.
- **Unlock on first encounter in context instead.** Each item arrives inside a whole the user already cares about, which gives it a retrieval cue and converts an infinite task into a sequence of finite ones. Then let them see everything they have already met that uses it.
- **Accept the planning cost.** Unlock-on-encounter means the user cannot survey the full space or estimate how far they are through it. That is a real loss; it is usually a smaller one than the wall.

## Apply to your product

- Which of your screens ask a user to recognise something new and apply it in the same action? What would a ten-second isolated introduction before that screen cost you?
- Where do you present a large reference set — every setting, every field, every shortcut — as a thing to be absorbed up front?
- What could unlock at first encounter in your product instead of being listed in advance, and what would the user lose in ability to plan?
